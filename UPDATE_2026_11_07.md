# MERGE project update — 7 November 2026

This repository contains both the official frontend/backend source and the previously exported hosted Living Museum under `museum-site/`. They are separate applications; retain the existing CORE when integrating.

## Included updates

- Passport or ID card selection at the first registration step, with passport upload support in the backend (commit e0ba335).
- Photo-based co-creation test page at `/preview/co-creation`: twelve industry selections, eight journey steps and links to existing application functions. The original homepage remains at `/`.
- Public SEO foundation: thirteen allowlisted pages, generated sitemap/robots and private-route noindex shell. Nginx configuration is included but requires environment-specific validation before deployment.
- Georgian, English and Russian clarification that account creation is separate from payment activation.
- Public repository/live-site audit and banking integration blockers. Audit findings for `tavdo/MERGE_STARS` must not be confused with this repository's newer code.

## Preview

From `frontend`, install with `npm ci`, then run `npm run dev -- --host 127.0.0.1 --port 5198 --strictPort`.
Open `http://127.0.0.1:5198/preview/co-creation`.
Build with `npm run build`, then check SEO artifacts with `node scripts/seo-foundation.test.mjs`.

## Deployment boundary

A GitHub push is not a confirmed update to mergestars.com. The deployment workflow remains manual. Identify and back up the actual production source/database/uploads before deploying: the public tavdo repository and the deployed museum were observed to differ.

No production credentials, identity documents, database exports or local browser state are included. Existing `museum-site/` export is preserved. This update does not claim working bank reconciliation, provider-backed Meshy generation, production authorization or full identity verification.
