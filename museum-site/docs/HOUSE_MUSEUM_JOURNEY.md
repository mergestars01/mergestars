ნივთის არჩევა ინარჩუნებს უკვე მოქმედ დათვალიერებას, ორიგინალის ფანჯარას, ტონის/მოზაიკის კონცეფციის პარამეტრებს, პირადი მონახაზის შენახვას და წყაროს ადგილობრივ ისტორიას. ეს მონახაზი **არ არის ახალი ავტორიტეტული CORE Version/Product ჩანაწერი**. სრული CORE ისტორია წინა ვერსიებშიც დაუკავშირებელი რჩებოდა.
